## 1. Executive Summary

TeaVision AI is a **decision-support tool** for Sri Lankan tea plantation managers, designed to automate leaf disease detection using U-Net semantic segmentation and EfficientNet classification. This document outlines the ethical considerations, regulatory compliance measures, and responsible deployment guidelines for the system.

### Key Principles

| Principle | Implementation |
|-----------|----------------|
| **Human-in-the-Loop** | All AI recommendations require human expert validation before action |
| **Transparency** | Full reasoning traces visible to users; no black-box decisions |
| **Non-Maleficence** | FN-weighted loss minimizes missed detections; errs toward caution |
| **Accountability** | Complete audit trail via reasoning traces and logs |
| **Beneficence** | Reduces pesticide overuse; supports sustainable agriculture |

## 4. AI Safety & Human Oversight

### 4.1 Decision Support, Not Autonomous Action

```
┌────────────────────────────────────────────────────────────────────┐
│                    AI DECISION HIERARCHY                           │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│   Level 4: FINAL DECISION → Human Expert (Estate Manager/TRI)     │
│                    ↑                                               │
│   Level 3: VALIDATION → Validation Agent (Source verification)    │
│                    ↑                                               │
│   Level 2: CONTEXTUALIZATION → Risk/Contraindication Agent        │
│                    ↑                                               │
│   Level 1: EVIDENCE RETRIEVAL → ChromaDB RAG + Evidence Agent     │
│                    ↑                                               │
│   Level 0: DETECTION → ML Models (Segmentation + Classification)   │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘

⚠️ TeaVision provides RECOMMENDATIONS only.
   All pesticide applications MUST be approved by qualified agronomists.
```

### 4.2 Risk Tier Thresholds

| Risk Tier | Threshold | Required Action |
|-----------|-----------|-----------------|
| 🟢 GREEN | composite_score < 10,000 | Monitor; no immediate action |
| 🟡 AMBER | 10,000 ≤ score < 50,000 | Review recommended; consider treatment |
| 🔴 RED | 50,000 ≤ score < 200,000 | Urgent review; contact field officer |
| ⚫ CRITICAL | score ≥ 200,000 | **Mandatory human expert consultation** |

### 4.3 False Negative Weighted Design

The system intentionally minimizes **False Negatives** (missed diseases) over **False Positives**:

```
Loss Function: L = α × Dice + (1-α) × BCE_weighted

Where: 
  - FN weight = 2.5 (higher penalty for missing disease)
  - FP weight = 1.0 (lower penalty for over-detection)
```

**Rationale:** Missing a disease outbreak (FN) has catastrophic economic impact (crop loss). Over-treating (FP) has recoverable cost (unnecessary pesticide).

## 5. Environmental & Agrochemical Compliance

### 5.1 Integrated Pest Management (IPM) First

TeaVision AI follows the IPM hierarchy mandated by TRI:

```
┌─────────────────────────────────────────────────────────────────┐
│              IPM HIERARCHY (TRI-Compliant)                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. CULTURAL METHODS (First Resort)                             │
│     - Shade management, sanitation, pruning                     │
│                                                                 │
│  2. BIOLOGICAL CONTROL                                          │
│     - Encourage natural predators                               │
│                                                                 │
│  3. BOTANICAL / ORGANIC                                         │
│     - Neem-based solutions, copper hydroxide                    │
│                                                                 │
│  4. CHEMICAL CONTROL (Last Resort)                              │
│     - Only TRI-approved fungicides/pesticides                   │
│     - Observing pre-harvest intervals                           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 5.2 Pre-Harvest Interval (PHI) Warnings

All chemical recommendations include mandatory PHI:

| Chemical | PHI (Days) | Target Disease |
|----------|------------|----------------|
| Copper Hydroxide | 7 | Blister blight, Algal leaf |
| Propiconazole | 14 | Brown blight |
| Mancozeb | 14 | Anthracnose |

### 5.3 Environmental Impact Considerations

| Factor | Mitigation |
|--------|------------|

| Water table protection | Advise buffer zones near water sources |
| Beneficial insects | Selective pesticides over broad-spectrum |

## 7. Bias & Fairness Considerations

### 7.1 Dataset Bias Analysis

| Bias Type | Assessment | Mitigation |
|-----------|------------|------------|
| **Geographic** | Dataset primarily from up-country estates | Future: include low-country, mid-country samples |
| **Cultivar** | Mostly TRI 2025, TRI 2026 varieties | Document model limitations for other cultivars |
| **Seasonal** | Training data spans multiple seasons | ✓ Adequate coverage |
| **Image Quality** | Lab-quality images predominate | ✓ Data augmentation applied |
| **Class Imbalance** | Some diseases underrepresented | ✓ Weighted sampling; class weights applied |

### 7.2 Model Limitations Disclosure

**TeaVision AI may perform suboptimally for:**

1. Cultivars not well-represented in training data (e.g., TRI 777, INTRI 6)
2. Diseases not in the 8-class taxonomy (novel pathogens)
3. Images with severe motion blur or occlusion
4. Mixed infections (multiple simultaneous diseases)
5. Non-standard image orientations

## 8. Limitations & Responsible Use

### 8.1 Intended Use

✅ **Appropriate Uses:**
- Preliminary disease screening on tea plantations
- Decision support for trained agronomists
- Educational tool for agricultural training
- Research prototype demonstration

❌ **Inappropriate Uses:**
- Sole basis for pesticide application without expert review
- Regulatory compliance certification
- Medical diagnosis of plant diseases (not certified)
- Critical infrastructure without human oversight
